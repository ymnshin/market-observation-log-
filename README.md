# Market Observation Log

日本株を中心に、米国株、為替、金利、原油、半導体・AIなどを日次で観察する**個人勉強用の市場ログ**です。

2026年8月3日から毎日記録しています。ニュースの要約だけでなく、価格・金利・為替・需給の関係を整理し、後から自分の見方を検証できるように残しています。

## Purpose

毎日の観察を、できるだけ次の順番で整理します。

1. **Fact** — 実際に起きた価格変化・公表データ
2. **Interpretation** — その値動きをどう解釈したか
3. **Scenario / Hypothesis** — 当時どんな仮説を置いたか
4. **Falsification** — 何が起きたら見方を修正するか

過去ログの一部は、公開用に「当時の観察・学習メモ」に簡略化しています。
